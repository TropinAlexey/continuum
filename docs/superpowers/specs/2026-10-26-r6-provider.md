# R6. A second budget provider (OpenAI or Gemini)

Status: draft
Date: 2026-10-26
Roadmap: [2026-10-26-roadmap.md](2026-10-26-roadmap.md)

## Problem

Agents are agent-agnostic now, providers are not: only `anthropic` (plus `spend` and `mock`).
A Codex or Gemini user on their own plan cannot watch their own window.

## Requirements

R6.1. Pick the provider whose usage/limit data is reachable with what the user already has
      (CLI login or API key), documented endpoint preferred; record the choice and why here
      before code.
R6.2. `providers/<name>.sh` (+ `.ps1`) prints the standard lines `<window> <util%> <reset_epoch>`,
      fails with a human message on stderr and non-zero exit, never prints a fake zero.
R6.3. Token lookup order documented; the token goes only to the provider's host; "What it
      touches" lists the endpoint and credentials.
R6.4. Tests with recorded responses (no network), both suites.

## Out of scope

Billing/spend for that provider beyond what R6.2 needs.

## Design

Follow `docs/writing-a-provider.md`; `mock.sh` is the template.

## Acceptance

`CONTINUUM_PROVIDER=<name> continuum status` works live once; tests green.
