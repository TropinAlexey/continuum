# Roadmap after v0.7.2

Status: agreed (backlog; each item gets its own spec before code)
Date: 2026-10-26

## Problem

v0.7.2 shipped bb, Junie and the weekly reset time. What remains:
- In a JetBrains IDE's AI chat the agent is your choice and runs through ACP; with Junie
  there is no warning (Junie's ACP host calls no hooks), other chat agents are unchecked.
- bb and most adapters have not been run live.
- The older backlog in `AGENTS.md` ("Дальше").

## Requirements (each becomes its own spec)

R1. **JetBrains IDE chat.** For each chat agent (Claude Agent, Codex, Junie via ACP) find out
    whether a continuum warning reaches it. For those that do not, show the warning in the IDE
    through its MCP server (same API in Rider and RustRover: JSON-RPC on
    `http://127.0.0.1:<port>/stream`), from `sh` + `curl` only, no new dependencies. First step:
    `tools/list` and whether any tool can put a message in front of the user.
R2. **Live checks.** bb thread (warning in a Claude thread; `continuum resume` → `bb thread tell`),
    Junie interactive TUI, Codex / Gemini / Cursor / opencode. Each with
    `CONTINUUM_THRESHOLD=10 CONTINUUM_TIERS=10` and the mock provider. Outcome: "run live" in the
    agents table, or a fix.
R3. **`continuum doctor`**: plugin enabled (`enabledPlugins`), legacy hooks, statusline copy drift,
    one command to migrate.
R4. **`StopFailure` (rate_limit)**: a note or notification "limit hit, resets at HH:MM,
    `continuum resume …`"; never a resume without the user's consent. Claude Code and Junie send
    the same fields (`error`, `error_details`).
R5. **`continuum install --agent <x>`** and a clean marketplace install test.
R6. **New provider** (OpenAI or Gemini) per `docs/writing-a-provider.md`.
R7. **Deeper bb integration** (get-bb/bb): usage from bb's own `provider-usage.v1` RPC (a Codex
    window at last), no double resume next to bb's `provider-retry`, warnings in non-Claude bb
    threads. Spec: [R7](2026-10-27-r7-bb-integration.md).
R8. **Small things**: `resume` at a date (weekly resets), `spend` without a fake zero, honest
    "sleep inhibited", removing the old `hooks/` forwarders (two releases), `.DS_Store` check,
    analyzer settings, uninstall that keeps the user's edits. Spec: [R8](2026-10-27-r8-small-fixes.md).

## Out of scope

Removing the `hooks/*.sh|ps1` forwarders (planned for v0.8, its own spec).
