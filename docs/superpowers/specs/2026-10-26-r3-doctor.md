# R3. `continuum doctor`

Status: done (v0.7.4)
Date: 2026-10-26
Roadmap: [2026-10-26-roadmap.md](2026-10-26-roadmap.md)

## Problem

Feedback 2026-10-23: the warning did not fire because an old copy was wired in and the
plugin was not the one running. Finding that took manual digging through settings files.

## Requirements

R3.1. `continuum doctor` prints one line per check, `ok` / `warn` / `fail`, and exits 1 on any
      `fail`. Read-only.
R3.2. Checks: provider answers (`continuum status`); state dir writable; `root` pointer valid;
      Claude Code plugin enabled (`enabledPlugins` in `~/.claude/settings.json`); legacy hooks
      still wired (`token-budget-check.sh`, `~/.claude/lib/usage.sh`, `hooks/*.sh` forwarders
      in settings); statusline copy in `~/.claude/hooks/` differs from the plugin's; Junie
      extension installed and its version vs the repo's.
R3.3. `continuum doctor --fix` applies only the safe fixes (refresh statusline copy, rewrite
      the root pointer) and prints the exact manual step for the rest (never edits
      `settings.json` hooks by itself).
R3.4. Same in `bin/continuum.ps1`; tests in both suites with fake HOME / settings files.
R3.5. "What it touches" lists every file doctor reads (Claude settings, `~/.junie/extensions`)
      and the two files `--fix` may write.

## Out of scope

Codex / Gemini / Cursor / opencode config checks (after R2 shows what breaks there).

## Design

`cmd_doctor` in `bin/continuum`, `Invoke-CntDoctor` in `.ps1`. JSON reading with grep/sed
like the adapters; no jq. Paths via `CLAUDE_CONFIG_DIR`, `JUNIE_HOME` overrides.

Implemented: `cmd_doctor` / `Invoke-CntDoctor`. Checks as R3.2, plus the version of the
plugin Claude Code actually runs (`~/.claude/plugins/cache/continuum/continuum/<ver>`) against
this code, since the 2026-10-23 feedback had three copies. Exit: 1 only on `fail`; `warn`
alone exits 0. The root pointer is rewritten by the CLI on every run, so it is rarely wrong
when doctor runs from the CLI; the check stays for copies outside the plugin.

## Acceptance

Tests: each check's ok and fail case in both suites. README "Troubleshooting" points to
`continuum doctor` first.
