# feedback/ — отзывы агентов (локально, в git не коммитится)

> Всё в этой папке, кроме этого README, игнорируется гитом (см. `.gitignore`).
> Пиши сюда после каждого meaningful использования continuum: что сработало, что нет, что улучшить.

## Имя файла

`feedback/YYYY-MM-DD-<агент>-<тема>.md`, например `feedback/2026-09-20-opencode-statusline.md`.

## Шаблон отзыва

```md
# Отзыв: <короткий заголовок>
- Дата:
- Агент (Claude Code / Codex / opencode / Cursor / ...):
- Версия continuum / коммит:
- Что делал (1–3 строки):
- Что сработало:
- Что сломалось / было непонятно (с командами и выводом):
- Предложения (конкретно, по приоритету):
- Оценка (1–5) + стоит ли повторить:
```

## Правила

1. Один файл = один опыт использования. Коротко, по фактам, с командами и выводом.
2. Не клади сюда секреты (токены, ключи, приватные пути вне проекта).
3. Мейнтейнер (любой агент в рабочей сессии) читает новые файлы отсюда перед планированием и переносит годное в `AGENTS.md` → «Дальше».
